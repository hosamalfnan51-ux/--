# 📖 تطبيق طريق القرآن الكريم - QuranWay

![QuranWay Banner](assets/hero_banner.png)

**تطبيق طريق القرآن (QuranWay)** هو تطبيق إسلامي شامل وذكي مكتوب بـ **Kotlin** و **Jetpack Compose** لنظام الأندرويد، يجمع بين المظهر الفاخر والتقنيات الحديثة لمساعدة المسلم في التلاوة، التجويد، الحفظ، والتدبر.

---

## 📱 طريقة تحميل وتثبيت التطبيق على هاتف سامسونج (Samsung / Android)

### الخطوة 1: تحميل ملف الـ APK المباشر
1. اذهب إلى قسم **Releases** أو **Actions** في هذا المستودع على GitHub.
2. اضغط على أحدث إصدار وتنزيل الملف باسم: `QuranWay-v1.0.apk`.

### الخطوة 2: تثبيت الملف على الهاتف
1. افتح ملف `QuranWay-v1.0.apk` المُنزل على هاتفك السامسونج.
2. إذا ظهرت لك رسالة "التثبيت من مصادر غير معروفة" (Install from Unknown Sources)، اضغط **سماح / Allow** لمستعرض الملفات أو المتصفح.
3. اضغط **تثبيت (Install)** وسيتم تثبيت التطبيق بنجاح على هاتفك مع أيقونة التطبيق المخصصة!

## 🌟 الميزات الرئيسية للتطبيق

- 🎙️ **معلم التلاوة والتجويد الذكي (AI Tajweed Coach):** تحليل صوتي لحظي لأحكام التجويد ومخارج الحروف مع تقديم ملاحظات دقيقة.
- 🔍 **البحث الدلالي الذكي (Semantic Quran Search):** البحث في القرآن الكريم بالمعاني والمواضيع والآيات العاطفية والروحية.
- 📖 **المصحف الشريف التفاعلي:** عرض النص القرآني بخط عثماني وتظليل أحكام التجويد مع صوتيات لأشهر القراء (المشاري العفاسي، الحصري، عبد الباسط، المعيقلي، الشريم).
- 📿 **حصن المسلم وموسوعة الأدعية:** أذكار الصباح والمساء والأدعية القرآنية والنبوية مع عداد تفاعلي.
- 🕋 **مواقيت الصلاة القادمة والقبلة:** حاسبة مواقيت دقيقة بناءً على الموقع الجغرافي.
- ⚙️ **الإعدادات والتفضيلات الدائمة:** حفظ سرعة التلاوة، اللغات (عربي/إنجليزي)، الوضع الليلي/النهاري، وحجم الخط باستخدام **Jetpack DataStore**.

---

## 🛠️ تقنيات التطبيق (Tech Stack)

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material Design 3)
- **Local Persistence:** Room Database + Jetpack DataStore Preferences
- **Architecture:** MVVM + Coroutines & Flow
- **AI Integration:** Server-side / Firebase Gemini API Integration
- **Build System:** Gradle (Kotlin DSL) with GitHub Actions CI/CD
